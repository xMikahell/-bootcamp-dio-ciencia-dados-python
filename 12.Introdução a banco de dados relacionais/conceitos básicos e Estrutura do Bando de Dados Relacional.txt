Estrutura de um Bando de Dados Relacional é basicamente composto por um DATABASE ou Bando de Dados
que vai ser armazenado conjuntos de todas as tabelas.
Bando de dados são formados por várias tabelas.

Características Princinpais de Bando de Dados Relacional

1. Relacionamento entre tabelas
2. Linguagem de Consulta Estruturada (SQL)
3. Integridade referencial
4. Normalização de dados
5. Segurança
6. Flexibilidade e extensibilidade
7. Suporte a transação ACID

ACID

A = Atomicidade
C = Consistência
I = Isolamento
D = Durabilidade 

As transações ACID, elas são conjuntos de propriedades de um bando de dados relacional
que garante que as operações elas sejam executadas de uma forma segura e confiável,
para ter as nossas informações consistentes.


SQL

SQL - Structured Query Linguage 


Organização do SQL

1. DQL - Linguagem de Consulta de Dados
1.1 SELECT;

2. DML - Linguagem de Manipulação de Dados
2.1 INSERT, UPDATE e DELETE 

3. DDL - Linguagem de Definição de Dados
3.1 CREAT, ALTER, DROP;

4. DCL - Linguagem de Controle de Dados
4.1 GRANT, REVOKE

5. DTL - Linguagem de transação de dados
5.1 BEGIN, COMMIT, ROLLBACK
